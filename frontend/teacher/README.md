# 教师端（Material UI）

路径：`frontend/teacher/`
演示：`index.html?demo=1`

## 角色入口

- 统一登录选择「体育任课老师」并登录成功后跳转本目录
- 无 token 时加 `?demo=1` 使用本地 MOCK

## 导航（四段主线）

- **工作台**：KPI + 准备/运行/录入/结课快捷卡
- **准备**：课程与名单、打卡设置、成绩规则（四项权重 + 专项子项 + 发布冻结）
- **运行**：打卡全览、学时与进度、审查中心（打卡 / 免测 / 免考 / 抵扣）
- **录入**：平时表现、体测录入、专项考试
- **结课**：成绩发布（总评、发布公示、申诉、导出预检）

归档由管理员发起；教师到「待归档」为止。

## 主要模块

| 文件 | 职责 |
|------|------|
| `app.js` | 路由、打卡下钻、审查中心、体测/专项、成绩发布表 |
| `core-loop.js` | 成绩规则、平时表现课次板、公示申诉 |
| `legacy-pages.js` | 名单导入、抵扣确认、导出预检/CSV、耐力跑试算 |
| `api.js` / `mock-data.js` | MOCK 数据与演示写操作 |

## 约束（业务流程 v3）

- 无课程任务；无组织负责人中转
- 打卡默认有效；标无效须通知；学时 0/1/2h；可补录学时；打卡分可覆盖
- 成绩规则发布后冻结；四项：打卡 / 专项 / 平时表现 / 体测
- 免测自定义分；免考不进专项录入
- 平时表现按课次出勤+扣分规则进总评（≠打卡分）
